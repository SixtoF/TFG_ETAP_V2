# ETAP - Sistema de Automatización de Tareas con IA

Este proyecto es un sistema de gestión y ejecución de tareas programadas (Scheduler) diseñado para el Trabajo de Fin de Grado (TFG). Utiliza una arquitectura de microservicios con Docker.

## Arquitectura Técnica
* **Backend:** FastAPI (Python 3.11)
* **Base de Datos:** PostgreSQL
* **Gestión de Colas:** Redis + Celery
* **Migraciones:** Alembic
* **Contenedores:** Docker & Docker Compose
